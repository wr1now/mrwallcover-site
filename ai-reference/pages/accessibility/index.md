Accessibility

# Using this site

The target is WCAG 2.2 AA. This page is not a certification, and an automated check is not a finished audit.

Pages use headings, visible keyboard focus and controls that can be used without dragging. The phone number stays hidden until you ask for it. Menus close with Escape. If motion or blur is a problem, use “Reduce visual effects” in the footer, or your system’s reduced-motion setting.

The material studio is optional. If WebGL is unavailable, the photograph and the written notes remain.

If something blocks you, email info@mrwallcover.com and say which page. We will help with the enquiry directly.
