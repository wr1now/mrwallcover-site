## What happens next

1. Dorin Burcus reads your note.
2. You can book a 20-minute call to talk the project through.
3. If the project needs a survey, we arrange it after we have spoken.
4. After the survey we write a scope of works by room.

## What helps us quote

None of this is required: a short note is enough to start. Each item you can send now is a question we will not need to ask later.

**The building and the rooms.** The address or area, the rooms, and a rough idea of the walls involved.

**The product code and colourway.** Or a link to the paper. A code is more useful than a description, because the code decides the labour. [Why the code matters](https://www.mrwallcover.com/advice/installation-cost/).

**Whether you already have it.** If the paper is already bought, a photograph of the roll labels helps; if it is still to be ordered, say so and we can source it.

**Photographs of the walls as they are.** Phone photographs are fine. They show the preparation the walls will need, which can be the larger part of the time on a period wall. [Wall preparation](https://www.mrwallcover.com/advice/wall-preparation/).

**Drawings or wall sizes, if you have them.** Elevations, or widths and heights. We measure on site, or from drawings when the programme needs it.

**Access and occupancy.** Stairs, high walls, working hours, and whether the house or hotel stays in use while we work.

**The date you have in mind.** We will say whether it is realistic. On a tender, give both the tender deadline and the start date.

## Five ways to begin.

### I already have the wallpaper

Installation, with the product you have bought. Measurements can wait.

### Help me choose and install it

A material family, a sample in the room, then the hang.

### I am specifying a project

Send the room schedule, drawings and the specification. Unknowns can stay blank.

### A hotel or contractor package

Access, programme and who supplies the material.

### Aftercare or a repair

A separate note for existing work. A photograph tells us whether it is the hang or the building.
