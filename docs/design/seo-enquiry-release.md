Existing FormSubmit alias, CAPTCHA, calculator/finder handoff, attachments and contact fallbacks remain. Tests intercept the native POST; no test enquiry is delivered. Production analytics and the optional private API remain off. This does not activate a CRM, notification service or sending workflow. [Intake contract and operational limits](../enquiry-intake.md).
