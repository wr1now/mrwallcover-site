# Calculator backgrounds — 17 October 2026

Adds faded, original wallpaper-roll, drop-measuring and wall-elevation drawings to the calculator. The roll uses the empty desktop hero margin; measuring marks stay at the outer form edge; the wall drawing sits beside the method text. Mobile crops are softer and the form-edge drawing is omitted at narrow widths.

`CalculatorBackdrop.astro` contains the original SVG linework. These drawings provide visual context, carry no dimensions or product artwork, and do not represent a calculated result or real project. Clipping is confined to the decorative layer and method panel so the sticky order summary retains its normal behaviour. No new image request, script or dependency is required.
